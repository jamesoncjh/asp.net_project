# ThreeAmigos (ThAmCo) Intranet Event Management System

An ASP.NET-based intranet platform for ThreeAmigos Corp to manage events, venues, and catering.

---

##  Scenario

You are a software developer at the fictional ThreeAmigos Corp, aiming to outstrip rival ManshaCo by entering the event management market. The intranet system you're building includes an external venue reservation service and a standalone catering service, which could later become a third-party offering.

---

##  About

**ThAmCo** (ThreeAmigos Corp) Intranet Event Management System enables organization employees to:

- Reserve venues using an external **Venue Reservation** service
- Order catering via a custom **Catering** service, which is designed for modular reuse or potential licensing to other companies

It embodies a decoupled, microservices-inspired architecture to separate concerns and support scalability and maintainability.

##  Features

- **External Venue Booking** – Interface with an off-site venue reservation web service
- **Modular Catering Service** – Self-contained service for catering requests, reusable beyond intranet scope
- **Clean, Intuitive UI** – Basic HTML/CSS/JavaScript front end for user interactions
- **ASP.NET-Powered Architecture** – Built using MVC or Web API conventions for maintainability
- **Separation of Concerns** – Logical isolation of services enables easy updates and reusability
